# alejandro-nicolas.fr

Page web simple : diaporama de photos, vignettes, agrandissement avec téléchargement, recherche Google, textes traduits selon la langue du navigateur.

## Contenu
- `index.html` : la page
- `kenny.png` : logo en haut à droite
- `favicon.png`, `favicon.ico` : icône de l'onglet
- `photos/` : photos d'origine (agrandissement et téléchargement)
- `photos-web/` : versions allégées 1024x768 (diaporama)
- `vignettes/` : miniatures 160x120
- `photos.zip` : toutes les photos d'origine (bouton « Télécharger toutes les photos »)

## Mise en ligne
Envoyer tous ces fichiers et dossiers au même niveau (racine du site).
